# FLOP Network Monitor

Unofficial community dashboard for FLOP Network.

## Features

- Live gateway monitoring
- Network detection
- AI model catalog
- Advertised token capacity
- Inference cost calculator
- Automatic refresh every 60 seconds

## Installation

Requires Node.js 22 or newer.

Run:

    node server.mjs

Open http://localhost:8787
